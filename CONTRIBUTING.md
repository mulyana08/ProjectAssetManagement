# Contributing

Thanks for contributing! Short guidelines to get started:

- Branching model: `main` = production, `develop` = active development, feature branches `feature/your-feature`.
- Work on a feature branch and open a PR to `develop`.
- PR checklist:
  - Provide a clear description and screenshots (if UI changes)
  - Link related issue (if any)
  - CI must pass (lint/build/tests)
  - At least one approving review

- Code style: follow existing project patterns. Frontend uses ESLint; run `npm run lint` in `frontend/` before opening PR.

Reporting issues: open an issue on the repo with steps to reproduce and expected vs actual behavior.
